
# Manual de Usuario

## Gestor de Clientes - Version 1.0

### Descripcion

El sistema permite registrar clientes ingresando su nombre y numero de telefono.

### Instrucciones de uso

1. Abrir el archivo index.html desde un navegador.
2. Ingresar el nombre del cliente.
3. Ingresar el telefono del cliente.
4. Presionar el boton "Registrar cliente".
5. Verificar que los datos aparezcan en la lista de clientes registrados.

### Comportamiento actual

En esta version, el campo telefono permite ingresar numeros y letras.

El sistema no realiza una validacion para comprobar que el telefono contenga solamente numeros.

### Ejemplo

Nombre: Diego Ponce

Telefono: ABC12345

Resultado: El sistema registra al cliente aunque el telefono contenga letras.
