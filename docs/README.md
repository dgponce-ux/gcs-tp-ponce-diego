
# Gestor de Clientes

## Descripcion del proyecto

El Gestor de Clientes es una aplicacion web sencilla que permite registrar clientes mediante un formulario.

Este proyecto fue desarrollado para el Trabajo Practico de Gestion de la Configuracion del Software (GCS).

## Version inicial

Version: v1.0

La version inicial permite registrar el nombre y telefono de un cliente.

Actualmente, el campo telefono acepta tanto numeros como letras, ya que todavia no cuenta con una validacion de formato.

## Tecnologias utilizadas

- HTML: estructura de la pagina.
- CSS: diseño de la interfaz.
- JavaScript: funcionamiento del formulario.
- Git: control de versiones.
- GitHub: repositorio y gestion de cambios.
